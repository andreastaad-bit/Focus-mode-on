## 📋 Descripción del proyecto

Este proyecto define la estructura de producción completa para un video de YouTube de formato largo orientado a la concentración profunda y el bienestar cognitivo. Combina:

- **Frecuencias binaurales** (Alfa 8–12 Hz y Gamma 40 Hz) para inducir estados de concentración
- **Visual ambiental** de río en bucle con paleta de colores tenues
- **Pausa creativa** con un doodle celestial animado para resetear la mente
- **Ejercicio de respiración** Box Breathing 4-4-4-4 guiado visualmente

## 🎵 Audio — Frecuencias Binaurales

### ⚠️ Requisito importante
> **Se requieren audífonos (earphones/headphones) para que el efecto binaural funcione correctamente.**  
> Cada oído recibe una frecuencia diferente; el cerebro genera la diferencia como una tercera frecuencia interna.

### Bloque 1 — Ondas Alfa (8–12 Hz)
- **Portadora:** 200 Hz (oído izquierdo) / 210 Hz (oído derecho)
- **Frecuencia de batimiento:** 10 Hz
- **Efecto:** relajación activa, estado de concentración ligera, entrada al flujo creativo
- **Capa ambiental:** sonido de río suave

### Bloque 2 — Ondas Gamma (40 Hz)
- **Portadora:** 200 Hz (oído izquierdo) / 240 Hz (oído derecho)
- **Frecuencia de batimiento:** 40 Hz
- **Efecto:** concentración máxima, procesamiento cognitivo de alta velocidad, estado de flow profundo
- **Capa ambiental:** mismo sonido de río, sutilmente más nítido

### Herramientas recomendadas para generar el audio
- [Brain.fm](https://brain.fm)
- [MyNoise.net](https://mynoise.net) (presets binaurales)
- Adobe Audition — plugin de tono binaural
- Generadores de tonos isocrónicos online

## ✏️ Pausa Creativa — Doodle Guiado

### Flujo de la pausa (01:00:00 – 01:10:00)

1. **Temporizador 15 segundos** — pantalla oscura, cuenta regresiva circular, texto: *"Toma tu lápiz y papel. Prepárate para fluir."*
2. **Doodle animado (9 min 45 s)** — un punto luminoso traza lentamente una imagen celestial. El usuario la sigue con lápiz y papel sin pensar, solo fluyendo.

### Imágenes celestiales sugeridas
- Luna creciente con espiral de estrellas
- Mandala circular con rayos solares
- Constelación conectada punto a punto
- Flor de loto geométrica
- Ojo cósmico con detalles de galaxia

### Herramientas para la animación de trazo
- **Adobe After Effects** — técnica `Stroke Trim Path`
- **Rive.app** — animación de path interactiva
- **Procreate** — exportar como GIF con path animation

## 🫁 Cierre — Box Breathing 4-4-4-4

### Ciclo de respiración (16 segundos por ciclo · ~37 repeticiones)

```
┌─────────────────────────┐
│  INHALA        SOSTÉN   │
│  ← 4 cuentas  4 cuentas →│
│                          │
│  SOSTÉN        EXHALA   │
│  ← 4 cuentas  4 cuentas →│
└─────────────────────────┘
        ● bola en movimiento
```

| Fase | Cuentas | Dirección de la bola | Color guía |
|---|---|---|---|
| Inhala | 4 | Sube por el lado izquierdo | `#A8D8EA` |
| Sostén (con aire) | 4 | Recorre la parte superior | `#E8D5A3` |
| Exhala | 4 | Baja por el lado derecho | `#B8E0B8` |
| Sostén (sin aire) | 4 | Recorre la parte inferior | `#D4A8C8` |
